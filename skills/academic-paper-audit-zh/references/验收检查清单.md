# 学术论文独立验收检查清单

本清单用于覆盖性检查，不是机械计分表。每项标记为“通过 / 存在问题 / 无法核实 / 不适用”，并记录对应位置和证据。

## 1. 研究事实完整性

- [ ] 研究对象、范围和条件与原始材料一致。
- [ ] 论文描述的方法、模型和算法确实被使用，或明确标为拟开展工作。
- [ ] 有相关实现材料时，模型结构、输入输出、损失函数、假设、参数与实际代码一致。
- [ ] 数据来源、样本量、纳入规则和预处理与记录一致。
- [ ] 实验/仿真设置、边界条件、荷载、对照和环境与原始记录一致。
- [ ] 数值、单位、分母、阈值和计算结果可以追溯。
- [ ] 没有把计划、意图或预期结果写成已完成工作。
- [ ] 没有编造结果、比较、消融实验、测试、审批或验证。
- [ ] 已报告论文、研究档案、代码、数据和日志之间的矛盾。

## 2. 文献与引用完整性

- [ ] 每条引用来源真实存在。
- [ ] 已核对作者、题名、年份、期刊/会议和 DOI/网址等元数据。
- [ ] 引用来源确实支持对应论断。
- [ ] 文献归属正确，没有把一篇论文的发现归给另一篇。
- [ ] 仅检查摘要的来源没有被描述为全文已读。
- [ ] 直接引文准确且可追溯。
- [ ] 没有明显遗漏重要基础研究或直接相关研究。
- [ ] 创新性、“首次”“尚无研究”等论断有足够检索依据。
- [ ] 现行标准和期刊要求采用了正确版本。
- [ ] 综述论文的来源选择和综合过程透明。

## 3. 写作计划符合性

- [ ] 论文符合已批准的论文类型和研究范围。
- [ ] 保留了核心研究问题。
- [ ] 已纳入批准的核心论断，或说明了省略原因。
- [ ] 没有将未经批准的方法、实验、结果或贡献擅自写成事实。
- [ ] 已反映用户对重要事实的修正。
- [ ] 研究档案中的未解决事项没有被静默写成已解决。
- [ ] 大纲确认后的重大变更有记录和依据。
- [ ] 缺少研究档案时，将计划符合性标记为未评价。

## 4. 论证与逻辑有效性

- [ ] 研究问题能够从背景和文献中自然推出。
- [ ] 研究空白具体且有证据。
- [ ] 研究目标可以由所述方法和证据回答。
- [ ] 方法确实针对研究问题。
- [ ] 假设已说明，并在研究范围内合理。
- [ ] 实验设计能够回答提出的问题。
- [ ] 基线和比较公平且描述充分。
- [ ] 结果支持相应解释。
- [ ] 讨论提供了进一步解释，而不是重复结果。
- [ ] 因果论断没有超出研究设计能力。
- [ ] 不存在无依据推断或逻辑跳跃。

## 5. 研究贡献与创新性

- [ ] 贡献具体，而不是只有形容词。
- [ ] 方法、理论、实证和工程贡献得到区分。
- [ ] 贡献与相关已有研究进行了比较。
- [ ] “首次”“创新”“前所未有”“填补空白”等表述有核验依据并且范围适当。
- [ ] 没有将一般实现工作误称为理论创新。
- [ ] 贡献的普适范围与实际验证范围一致。

## 6. 结果与结论一致性

- [ ] 结果报告足以支持主要论断。
- [ ] 重要负面、无显著差异、混合或意外结果没有被隐藏。
- [ ] 统计论断具有必要的检验、假设和不确定性信息。
- [ ] “显著”没有混淆统计显著和一般意义上的明显。
- [ ] 结论回答了研究问题。
- [ ] 结论没有引入新发现。
- [ ] 结论没有超出实际测试条件。
- [ ] 局限性具体且有意义。
- [ ] 未来工作没有被写成当前已经具备的能力。

## 7. 论文类型、结构与期刊规范

- [ ] 论文类型识别正确。
- [ ] 结构符合论文类型和学科习惯。
- [ ] 综述进行了综合分析，而非仅罗列文献。
- [ ] 系统综述/范围综述报告了真实检索和筛选过程。
- [ ] 荟萃分析报告了适当的定量综合。
- [ ] 方法论文包含足够技术说明和验证。
- [ ] 摘要准确反映正文。
- [ ] 各章节功能清楚且恰当。
- [ ] 指定目标期刊时已检查其现行要求。
- [ ] 未核实期刊要求时，没有声称格式完全合规。

## 8. 学术表达与去人工智能化质量

- [ ] 引言没有过多泛泛背景，能够进入具体研究问题。
- [ ] 段落具有清楚的中心任务。
- [ ] 句子之间信息衔接自然。
- [ ] 对照结构只用于真实概念区别。
- [ ] 衔接词表达真实逻辑关系。
- [ ] 已删除空泛赞美和无依据的影响力表述。
- [ ] 已删除无关研发过程和被放弃方案的冗长叙述。
- [ ] 技术术语稳定、准确。
- [ ] 摘要、引言、结果、讨论和结论之间的重复受到控制。
- [ ] 语言清楚，不刻意堆砌复杂表达。
- [ ] 没有把所有结果都写成正面结果。
- [ ] 有证据支持且经确认的核心论断保留了合理强度；不存在未解释的实质性弱化或撤回。
- [ ] 新增的模糊措辞、限定、免责声明和范围限制有具体证据或读者理解需要作为依据。
- [ ] 真实局限和必要不确定性得到保留，同时避免重复或比例失当的免责声明。
- [ ] 没有把假想审稿意见自动写入正文。
- [ ] 有基准时对照并记录实质性论断变化；无基准时不推断不可见的修改历史。

## 9. 研究透明度、可复现性和图表完整性

- [ ] 方法细节达到该论文类型所需的可复现程度。
- [ ] 数据/材料可用性声明准确。
- [ ] 伦理、知情同意、资助、利益冲突和作者贡献声明准确（如适用）。
- [ ] 图表编号一致，且正文均有引用。
- [ ] 图题、表题、图注、表注、单位、坐标轴、图例和缩写清楚。
- [ ] 已在材料提供时检查图表底层数据。
- [ ] Markdown 转换没有丢失图、表、公式、题注或补充材料引用。
- [ ] 图片链接可访问，或缺失资源已明确标记。
- [ ] 数学符号和公式一致。
- [ ] 人工智能使用披露符合目标期刊现行政策。

## 10. 中文论文专属检查

- [ ] 中文正文以中文为主体，没有无必要的英文词汇夹杂。
- [ ] 存在规范中文术语时，优先采用中文名称。
- [ ] 首次出现的必要英文缩写采用“中文名词（英文全称，英文缩写）”格式，或符合期刊明确要求。
- [ ] 后续优先使用中文术语，缩写的使用频率和范围合理。
- [ ] 同一术语全文统一，没有多种译名混用。
- [ ] 软件、模型、算法、机构和数据集专名没有被错误汉化。
- [ ] 英文全称、缩写的大小写和拼写准确。
- [ ] 没有英文逐词翻译形成的欧化长句。
- [ ] 没有过度名词化、被动句堆叠和不必要的“的”字结构。
- [ ] 没有机械使用“首先、其次、最后”“值得注意的是”“综上所述”等套话。
- [ ] “不是……而是……”等对照句式没有滥用。
- [ ] 中英文混排、中文标点、括号、引号和空格一致。
- [ ] 数字、单位、量符号和公式符合适用规范。
- [ ] 中文摘要和英文摘要内容一致，且符合目标期刊要求。
- [ ] 关键词准确、具体，具有检索意义。
- [ ] 中文图表题注、图例和表注完整，且术语与正文一致。
- [ ] 参考文献原始书目信息未被随意翻译或改写。
