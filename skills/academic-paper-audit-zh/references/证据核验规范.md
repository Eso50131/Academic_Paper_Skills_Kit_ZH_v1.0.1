# 独立验收证据核验规范

## 1. 什么可以作为证据？

应根据论断类型匹配证据。

| 论断类型 | 适当证据 |
|---|---|
| 用户实际实现的方法 | 源代码、配置、版本化代码仓库、运行日志、技术记录、用户确认 |
| 数据集/样本论断 | 原始数据集、数据字典、采集方案、样本清单 |
| 数值结果 | 原始/处理后数据、可复核计算、分析脚本、实验日志 |
| 方法/理论论断 | 原始论文、形式化推导、官方技术规范 |
| 文献现状论断 | 相关原始论文和足够广泛的检索策略 |
| 标准/合规论断 | 当前官方标准/规范及适用条款 |
| 期刊要求 | 当前官方投稿指南或编辑政策 |
| 图表论断 | 原始图片、底层数据、绘图脚本、题注和来源标注 |

论文中的句子不能作为证明自身正确的证据。研究档案是研究地图，不是原始来源。用户确认能够证明用户作出了该确认，但若原始数据可供检查，它不能替代原始数据核验。

## 2. 证据状态

使用以下状态之一：

- **已核实：** 已检查的一手证据直接支持该论断，且范围一致。
- **有限支持：** 证据仅支持较窄或有条件的表述。
- **无支持依据：** 当前可用证据不支持该论断。
- **存在矛盾：** 已检查证据与该论断冲突。
- **无法核实：** 必需证据缺失或无法访问。
- **不适用：** 无需检查该项证据。

不得将“无法核实”归为“错误”。不得将“用户已确认”等同于“独立核实”。

## 3. 外部检索流程

对外部论断：

1. 提取需要核验的准确命题。
2. 确定最直接的来源类型。
3. 检索原始出版机构或官方来源。
4. 打开来源，检查相关段落、表格、图片或条款。
5. 记录书目信息和访问日期。
6. 比较来源实际支持范围与论文表述。
7. 明确说明无法核验的内容。

创新性论断应扩展术语和相邻学科检索。少数搜索结果不能证明不存在先前研究。

现行标准和期刊政策应检查发布机构或期刊官网，并记录版本/实施日期。

如果搜索工具不可用，应列出尚未独立检查的具体论断，不得写“已经通过文献检索核验”。

## 4. 定量结果核验

对每项重要数值论断，检查：

- 原始来源和文件/版本。
- 单位及换算。
- 分子和分母。
- 样本量和排除项。
- 汇总与平均方法。
- 阈值和通过/失败定义。
- 舍入和有效数字。
- 缺失值和异常值处理。
- 统计检验、假设、置信区间和 P 值（如适用）。
- 比较条件是否等价。

在数据和工具允许时重新计算。如果只提供汇总表，应说明未完成原始数据核验。

## 5. 方法与实现核验

将论文中的方法描述与实际实现对照：

- 模型/算法名称和结构。
- 输入输出表示。
- 损失函数/优化目标。
- 训练和推理流程。
- 超参数和配置。
- 数据预处理。
- 数值求解器/软件版本及设置。
- 假设和边界条件。
- 评价指标和验收标准。

不得根据“通常做法”推断实际实现。代码缺失或不完整时，相关实现论断应标记为无法核实。

## 6. 文献核验

对每条重要文献检查：

- 文献是否真实存在。
- 作者、题名、年份、期刊和 DOI 等元数据。
- 出版状态：同行评审论文、预印本、撤稿、勘误或更正。
- 与论断的相关性。
- 实际被归属的方法或结果。
- 论文是否夸大或误述来源。
- 是否存在更直接的原始来源。

来源已撤稿或更正时，应报告其状态和影响。

## 7. 图表核验

逐项检查图表：

- 是否存在于交付材料包。
- 编号和正文引用是否一致。
- 题注、图例、坐标轴、单位、样本量、附注和来源是否清楚。
- 有底层数据时，是否与图表数值一致。
- 是否存在无法解释的裁剪、缺失分图、比例尺不一致或无依据标注。
- 环境允许时，检查 Markdown 图片路径是否可访问。
- 缺少原始资源时，报告具体限制，不推断未看到的图表内容。

## 8. 问题的证据格式

每项问题记录：

- 问题编号。
- 论文位置。
- 原文论断/引文。
- 证据状态。
- 证据来源和位置。
- 证据为什么支持或不支持该论断。
- 严重程度及理由。
- 建议修正动作。

没有证据时，不得轻率指控学术不端。优先使用中性表述：“现有材料不足以支持”“与已检查记录不一致”“无法根据当前材料核实”。
