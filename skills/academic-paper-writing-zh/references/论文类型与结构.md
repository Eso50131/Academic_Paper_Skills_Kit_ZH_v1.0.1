# 论文类型与结构

本文件用于判断论文的学术任务并选择合适结构。各类别是按研究任务划分，并非互斥。一篇论文可以同时具有方法研究和计算研究特征，也可以同时属于实证研究和比较研究。

## 1. 先判断论文要完成什么学术任务

| 论文类型 | 核心学术任务 | 常见叙事主线 |
|---|---|---|
| 原创研究论文 | 提出并支持新的研究发现 | 问题 → 方法 → 证据 → 解释 → 有边界的结论 |
| 实验/实证研究 | 使用观察或数据检验问题、假设 | 问题 → 研究设计 → 数据 → 分析 → 发现 |
| 计算/数值/仿真研究 | 建立或应用计算模型并评价结果 | 问题 → 模型与假设 → 实现 → 验证/确认 → 结果 |
| 方法论文 | 提出或实质改进一种方法 | 需求/现有局限 → 方法依据 → 方法说明 → 比较/验证 → 适用范围 |
| 理论/概念论文 | 建立、修订概念、理论或形式化关系 | 概念问题 → 既有理论 → 假设 → 推导/论证 → 含义与边界 |
| 案例研究 | 深入研究一个边界明确的现实案例 | 案例依据 → 背景 → 方法 → 案例证据 → 解释与可迁移性 |
| 比较研究 | 比较方法、系统、材料或案例 | 比较问题 → 公平的比较方案 → 统一评价标准 → 结果 → 原因解释 |
| 叙述性综述 | 解释和梳理某一领域的研究 | 主题地图 → 分类综合 → 争议/空白 → 研究展望 |
| 批判性综述 | 评价既有证据、假设和局限 | 综述问题 → 分析标准 → 批判性综合 → 未解决问题 |
| 系统综述 | 使用可复核的检索和筛选方法回答明确问题 | 问题/方案 → 检索 → 筛选 → 质量评价/提取 → 综合 |
| 范围综述 | 描绘领域证据范围、概念和研究空白 | 范围问题 → 检索/筛选 → 信息提取 → 证据地图 → 空白 |
| 荟萃分析 | 对定量研究结果进行统计综合 | 问题 → 系统识别研究 → 效应量提取 → 统计综合 → 异质性/敏感性分析 |
| 整合性综述 | 跨方法或跨学科整合证据 | 概念范围 → 证据收集 → 整合框架 → 综合 |
| 伞式综述 | 综合已有系统综述或荟萃分析 | 综述之综述问题 → 综述筛选 → 重叠/质量 → 综合 |
| 短篇研究通讯/研究快报 | 传达聚焦且具有时效性的研究发现 | 问题 → 关键方法/结果 → 精简证据与意义 |
| 技术札记 | 说明范围有限的技术进展或修正 | 技术问题 → 解决方案 → 示范与边界 |
| 数据论文 | 说明可复用数据资源 | 数据需求 → 数据构建 → 结构/质量/验证 → 获取与复用 |
| 软件论文 | 说明研究软件资源 | 研究需求 → 设计/实现 → 验证/基准测试 → 获取与复用 |
| 学术观点/评论/立场论文 | 提出有论据支持的学术观点 | 背景 → 明确主张 → 证据与论证 → 含义/反方观点 |

## 2. 论文类型不等于研究方法

不得仅根据某一种工具或技术判断论文类型。

- 有限元分析是一种研究方法，不是论文类型。
- 机器学习是一类研究方法，不是论文类型。
- 问卷可以作为实证研究中的数据收集方法。
- 系统综述由透明、可复核的综述方法界定，不由引用文献数量决定。
- 荟萃分析是定量综合方法，可以包含在系统综述中，但两者不能互换。
- 案例研究还可以同时采用计算、实验或比较方法。

如果多个标签都适用，应确定一个主要类型，并说明次要研究特征。

## 3. 结构选择

### 3.1 原创实证或计算研究

常见结构为引言—方法—结果—讨论结构（Introduction, Methods, Results, and Discussion，IMRaD），但并非所有学科和期刊都采用这一结构。

工程与计算研究也可能采用：

1. 引言
2. 相关研究/文献综述
3. 问题定义或理论基础
4. 方法/模型构建
5. 实验或数值分析方案
6. 结果
7. 讨论
8. 结论

只有当目标期刊和论证需要时，才合并“结果与讨论”。当验证与确认的区别重要时，可以单独设置相应章节。

### 3.2 方法研究

必须说明：

- 方法解决什么问题。
- 相对于已有方法，技术上的新内容是什么。
- 为什么采用这些设计选择。
- 方法是否被充分说明，以便理解和复现。
- 哪些验证、基线比较、消融实验或压力测试支持该方法。
- 方法适用和不适用的范围。

除非其新颖性和价值已得到证明，否则不得把一般实现细节包装成方法创新。

### 3.3 理论/概念研究

明确区分：

- 定义。
- 假设。
- 公理或前提。
- 命题。
- 推导。
- 解释。
- 猜想。
- 局限。

不得把直觉类比写成数学证明。应明确命题成立所需的条件。

### 3.4 叙述性和批判性综述

可按有分析意义的维度组织文献：

- 研究问题或子问题。
- 方法类别。
- 理论框架。
- 数据/材料类型。
- 应用领域。
- 历史演进（仅当时间线本身能够解释领域发展时）。
- 研究发现、分歧或证据质量。

避免每篇论文各占一个段落的目录式写法。每个主题部分都应比较、综合并评价多篇来源。

### 3.5 系统综述、范围综述和荟萃分析

这些类型必须具有真实的方法记录，不能只写出“看起来像系统综述”的论文。正式写作前应确认：

- 综述问题和范围。
- 研究方案或预注册情况（如有）。
- 实际检索的数据库和其他来源。
- 检索式和检索日期。
- 纳入与排除标准。
- 筛选流程及真实数量。
- 数据提取/信息整理字段。
- 质量评价或偏倚风险方法（如适用）。
- 综合方法；荟萃分析还需说明效应量、统计模型、异质性和敏感性分析。

相关时使用现行系统综述和荟萃分析报告规范（Preferred Reporting Items for Systematic Reviews and Meta-Analyses，PRISMA）：系统综述可参考 PRISMA 2020，范围综述可参考 PRISMA-ScR；干预研究综述可查阅最新版 Cochrane Handbook。写作前核对最新版本。不得虚构任何步骤或数量。人工智能助手完成的一次网页检索，不自动等于可复现的系统检索。

### 3.6 数据论文和软件论文

重点说明：

- 资源用途和预期复用方式。
- 来源、采集/构建过程。
- 数据结构、质量控制、许可、访问方式和局限。
- 软件架构、依赖、版本、测试、基准测试和可用性。
- 可复现性和维护状态。

未核实链接和访问状态前，不得声称数据集或软件已经公开可用。

### 3.7 学术观点和评论

明确提出核心主张。区分已有证据、作者解释和建议。公平呈现重要反方观点。不得把个人观点伪装成系统证据综述。

## 4. 摘要和结论应随论文类型变化

原创研究摘要通常说明问题、方法、实际关键结果和结论；综述摘要应说明范围和综合方法；学术观点摘要应突出主张及其意义。

结论应回答论文的核心问题，说明有证据支持的贡献及边界。不得引入新结果、夸大影响，也不应逐节重复全文。

## 5. 目标期刊要求优先

用户指定目标期刊或会议后：

1. 检索其当前官方投稿指南。
2. 核对接受的文章类型、章节结构、篇幅/摘要限制、参考文献格式、图表规则、补充材料和人工智能使用披露政策。
3. 只有核实后才应用期刊特定要求。
4. 未指定目标期刊时，采用符合学科惯例的通用结构，并明确说明尚未完成期刊格式适配。
